# 📝 Notepad

A lightweight desktop notepad application built with **VB.NET**.

## Overview

Notepad is a desktop application project for working with text through a simple graphical interface.

## Tech Stack

- Visual Basic .NET
- Windows Forms
- Visual Studio

## Getting Started

1. Clone or download this repository.
2. Open the solution file in Visual Studio.
3. Restore any required dependencies.
4. Build and run the project.

## Project Structure

Open the solution/project files in Visual Studio to explore the application source.
